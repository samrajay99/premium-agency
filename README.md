# Best Escorts Hyderabad - Premier Luxury Companion Directory

A high-performance, mobile-first luxury adult companionship and escort directory built with Next.js App Router for Hyderabad, featuring 100% verified companion profiles, 5-star hotel outcall booking, and complete client discretion.

## Tech Stack

- Next.js 15 (App Router) & React 19
- TypeScript & Tailwind CSS
- Lucide React icons
- Dynamic search & multi-tier filtering (by locality, model category, and name)
- SEO Optimization (JSON-LD Structured Data, Canonical URLs, Open Graph, Sitemap & Robots)

## Development Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the application.

## Production Build

```bash
npm run build
npm run start
```

## Features

- **100% Verified Profiles:** Complete photo galleries, bio details, languages, rates, and verified status.
- **Hyderabad Area Indexing:** Comprehensive outcall coverage across Banjara Hills, Jubilee Hills, HITEC City, Gachibowli, Madhapur, Begumpet, Somajiguda, Kukatpally, Miyapur, Kondapur, Ameerpet, and Secunderabad.
- **Direct Concierge Integration:** Instant WhatsApp and Click-to-Call booking actions.
- **Client Anonymity:** Strict privacy protocols and zero personal client tracking.
